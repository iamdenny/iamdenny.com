브라우저 게임
입력 문제 해결하기

키보드나 터치가 작동하지 않을 때는 게임 자체의 오류인지, 브라우저 포커스나 지원 입력 방식의 차이인지 나눠 살펴보세요. 먼저 게임 페이지에 적힌 조작 안내와 호환성 정보를 확인하면 불필요한 재시도를 줄일 수 있습니다.

문서 업데이트: 2026년 10월 25일

이 글 목차

  1. 첫 1분 점검
  2. 키보드와 터치가 반응하지 않는 경우
  3. 게임패드 호환성을 확인할 때
  4. 문제가 계속되면 기록할 정보

첫 1분 점검

  1. 게임별 안내를 엽니다. 게임 소개에 표시된 키와 터치 동작을 확인합니다. 같은 사이트에 있는 게임이라도 이동, 선택, 일시정지 키가 같다고 가정하지 마세요.
  2. 게임 영역을 한 번 선택합니다. 브라우저에서 다른 버튼이나 주소창에 포커스가 있으면 게임이 키 입력을 받지 못할 수 있습니다. 게임 영역을 클릭하거나 탭한 뒤 안내된 키를 눌러 봅니다.
  3. 한 가지 입력 방식만 시험합니다. 화면 버튼이 있는 게임은 버튼을 먼저 누르고, 키보드 게임은 해당 게임의 키를 사용합니다. 동시에 여러 입력 장치를 연결하면 어떤 장치가 반응했는지 구분하기 어렵습니다.
  4. 입력 진단 페이지를 사용합니다. 키보드·터치·게임패드 테스트 화면에서 브라우저가 입력을 받는지 확인합니다. 진단 통과는 현재 브라우저가 입력 이벤트를 받았다는 뜻이지, 모든 게임 동작이 정상이라는 보증은 아닙니다.

키보드와 터치가 반응하지 않는 경우

키보드로 게임을 할 때는 먼저 게임 영역을 선택하고, 게임별로 지정된 화살표 키나 문자 키를 짧게 눌러 보세요. 브라우저 탭이 비활성화됐거나 주소창에 커서가 있을 때 입력은 게임에 전달되지 않습니다. 입력 진단에서 키가 표시되는데 한 게임만 반응하지 않는다면 그 게임의 조작 안내를 다시 보고 다른 지정 키가 있는지 확인합니다.

터치 화면에서는 버튼의 실제 터치 영역이 화면의 그림과 다를 수 있습니다. 버튼 중앙을 눌러 반응을 확인하고, 화면 확대나 브라우저 번역이 켜져 있다면 기본 보기에서 다시 시도합니다. 게임이 가로 화면이나 전체 화면을 요구하는지는 해당 게임의 안내를 따르세요. 모든 게임이 화면 방향 전환을 지원하는 것은 아닙니다.

게임패드 호환성을 확인할 때

게임패드가 기기에 연결됐다고 해서 모든 브라우저와 모든 게임이 같은 버튼 배열로 인식하는 것은 아닙니다. 호환성 안내에서 확인된 입력 종류와 아직 시험되지 않은 기기 목록을 읽고, 연결 직후 입력 진단에서 버튼이 감지되는지 확인하세요. 진단되는 버튼이 게임 안에서 어떤 기능을 하는지는 각 게임의 키 배치에 따라 달라집니다.

호환성 표현을 구분하세요

코드나 자동 브라우저 점검으로 확인한 키보드·터치 입력은 실제 iPhone, Android, Xbox·DualSense 컨트롤러, 차량 화면 등 모든 기기의 현장 테스트와 같지 않습니다. 안내에 미검증으로 표시된 장치는 지원된다고 단정할 수 없습니다.

문제가 계속되면 기록할 정보

  • 게임 이름과 게임 안의 조작 안내
  • 기기 종류와 운영체제 버전, 브라우저 이름과 버전
  • 키보드·터치·게임패드 중 어떤 입력을 사용했는지
  • 입력 진단 화면에서는 입력이 감지됐는지
  • 문제가 난 시점과 다시 시도해도 같은 결과인지

오류 제보에는 계정 비밀번호나 불필요한 개인정보를 포함하지 마세요. 위 정보를 함께 보내면 특정 게임의 안내와 입력 문제를 구분하는 데 도움이 됩니다. 진단이나 호환성 표기는 테스트한 환경 범위 안에서만 해석해야 합니다.
