종이 스퀴시 도안
고르고 인쇄하기

도안 목록은 찾고 비교하는 출발점입니다. 미리보기나 가격 필터만 보고 인쇄·재배포 조건을 결정할 수는 없습니다. 제작자 원문을 확인한 다음 용지와 출력 설정을 맞추면 만들기 전에 막히는 일을 줄일 수 있습니다.

문서 업데이트: 2026년 10월 25일

이 글 목차

  1. 필터는 원하는 자료를 좁히는 데 씁니다
  2. 원작자 페이지에서 이용 조건 확인하기
  3. A4 출력 전에 점검하기
  4. 목록 정보의 한계

필터는 원하는 자료를 좁히는 데 씁니다

말랑모아에서는 캐릭터나 주제, 제작자, 난이도, 도안 형태, 무료 여부와 제공 방식을 기준으로 목록을 좁힐 수 있습니다. 바로 출력하도록 준비된 자료인지, 제작자 페이지에서 도안을 받아야 하는지에 따라 다음 단계가 다를 수 있습니다.

  • 형태를 봅니다. 접거나 펼치는 도안, 스퀴시북 형식, 형태 정보가 확인되지 않은 자료를 구분해 필요한 만들기 방식을 찾습니다.
  • 비용 표시를 읽습니다. 무료, 유료와 확인되지 않은 자료는 서로 다른 상태입니다. 가격을 알 수 없음은 무료라는 뜻이 아닙니다.
  • 난이도와 제작자를 살핍니다. 칼이나 풀이 필요한지, 안내 영상이 있는지, 원작자가 어떤 순서로 만들도록 설명했는지 원문에서 확인합니다.
  • 제공 방식이 맞는지 확인합니다. 목록의 미리보기만으로 인쇄 파일이 포함된다고 가정하지 말고 원문 페이지로 이동합니다.

원작자 페이지에서 이용 조건 확인하기

도안마다 제작자와 이용 조건이 다를 수 있습니다. 출력하기 전에 원문에서 개인 이용, 수업용 인쇄, 파일 재배포, 상업적 이용, 출처 표시를 어떻게 다루는지 읽으세요. 목록의 무료 표시나 다운로드 링크는 저작권 허락의 범위를 대신하지 않습니다.

원문이 삭제됐거나 이용 규칙을 찾을 수 없다면 허용된 자료라고 추측하지 말고 제작자에게 확인하거나 다른 도안을 고르세요. 누군가의 동영상이나 게시물을 보고 다시 올린 사본보다 제작자가 직접 제공하는 링크를 우선 이용합니다. 미리보기 이미지는 제작자 표시와 원문 링크가 함께 있어도 파일 자체를 재배포할 권리를 주지는 않습니다.

특히 확인할 항목

수업이나 모임에서 여러 장 인쇄하려는 경우, 참가자에게 파일을 나눠 주려는 경우, 만든 결과물을 판매하거나 공개하려는 경우에는 각각의 이용 조건이 다를 수 있습니다. 원문에 적힌 허용 범위와 출처 표시 방법을 그대로 따르세요.

A4 출력 전에 점검하기

  1. 원문에서 파일과 용지를 확인합니다. 자료가 A4를 기준으로 만들어졌는지, 컬러 인쇄가 필요한지 읽어 보세요.
  2. 인쇄 미리보기를 봅니다. 페이지 방향, 잘림, 여백과 여러 페이지 나눔을 확인합니다. 안내가 없다면 우선 원본 크기 또는 실제 크기(100%)로 테스트 인쇄하세요.
  3. 선이 읽히는지 확인합니다. 접는 선, 자르는 선과 풀칠 구역이 흐리거나 페이지 밖으로 잘리지 않는지 작은 시험 출력으로 살펴보세요.
  4. 종이와 잉크를 정합니다. 일반 복사용지에서 모양이 무너지면 더 두꺼운 종이를 시험할 수 있지만, 프린터가 지원하는 용지 무게를 확인하세요.
  5. 한 장으로 조립 순서를 확인합니다. 완성 전에 예시 한 장을 자르고 접어 보고, 필요한 도구와 조립 시간을 가늠합니다.

목록 정보의 한계

목록의 가격, 분류, 난이도와 형태는 검색을 돕는 정리 정보입니다. 제작자가 원문을 수정하거나 링크가 바뀌면 표시가 최신이 아닐 수 있습니다. 최종 비용과 이용 권한, 안전 안내는 제작자 페이지의 최신 설명을 기준으로 확인해 주세요. 작은 부품이나 가위·칼·접착제를 사용할 때는 어린이가 보호자와 함께 작업하도록 안내하세요.

말랑모아에서 원문이 열리지 않거나 잘못된 분류를 발견하면 오류 제보와 제안 링크로 자료 이름과 문제가 난 페이지를 알려 주세요. 제보에는 로그인 정보나 불필요한 개인 내용을 넣지 않아도 됩니다.

조건을 확인하고 도안을 찾아보세요

주제와 형태를 좁힌 뒤 제작자 페이지에서 최신 파일과 이용 조건을 확인할 수 있습니다.
