비례 도형으로
수치를 읽는 법

비교 그림은 숫자의 차이를 빠르게 보여주지만, 어떤 도형이 어떤 값을 나타내는지 알아야 정확히 읽을 수 있습니다. 면적을 나타내는 정사각형, 지름을 나타내는 원, 한 가지 수치의 막대는 서로 다른 의미를 가집니다.

문서 업데이트: 2026년 10월 25일

이 글 목차

  1. 면적은 정사각형의 넓이로 비교합니다
  2. 원은 행성의 지름을 보여줍니다
  3. 막대는 선택한 한 가지 값을 비교합니다
  4. 출처 값과 직접 입력한 값을 구분하세요

면적은 정사각형의 넓이로 비교합니다

나라의 면적을 정사각형으로 나타낼 때는 정사각형의 넓이가 실제 면적에 비례합니다. 한 나라의 면적이 다른 나라의 4배라면 정사각형의 넓이는 4배지만, 한 변의 길이는 4배가 아니라 2배입니다. 넓이는 가로와 세로를 함께 곱하기 때문입니다.

넓이 1배
한 변 1배
넓이 4배
한 변 2배

넓이를 4배로 나타내려면 한 변은 2배로 그립니다. 도형의 길이만 보고 넓이 차이를 짐작하지 않도록 주의하세요.

원은 행성의 지름을 보여줍니다

행성을 원으로 나란히 그릴 때 Denny Compare는 지름을 비교합니다. 이 그림은 행성의 실제 표면 윤곽이나 부피를 표현하지 않습니다. 원의 크기만으로 행성의 질량, 표면적 또는 부피 차이를 읽을 수는 없습니다.

막대는 선택한 한 가지 값을 비교합니다

막대는 길이, 높이처럼 선택한 하나의 수치를 비교할 때 사용합니다. 나라 면적을 나타내는 정사각형이나 행성 지름을 나타내는 원과는 해석 방법이 다르므로, 화면에 표시된 비교 대상과 단위를 먼저 확인하세요.

출처 값과 직접 입력한 값을 구분하세요

비교 페이지에는 값, 단위, 계산 방식과 출처가 표시됩니다. 직접 입력한 두 번째 값은 출처가 있는 측정치가 아니라 사용자가 정한 기준값입니다. 예를 들어 기준을 10으로 놓고 비교하면 결과는 입력한 기준에 대한 비율이지, 외부에서 검증한 실제 데이터라는 뜻은 아닙니다.

  • 비교 전에 두 값의 단위가 같은지 확인합니다.
  • 출처가 있는 값은 해당 항목의 출처를 열어 맥락을 확인합니다.
  • 비교 순서를 바꾸면 표시되는 비율이 역수가 될 수 있습니다.
  • SVG로 저장하면 이름과 수치를 포함한 그림을 문서에 사용할 수 있습니다.
비교 결과를 공유할 때

그림만 전달하기보다 대상 이름, 값과 단위도 함께 확인할 수 있게 공유하세요. 직접 입력한 기준값을 사용했다면 그 값이 사용자 입력임을 밝혀 주세요.

수치를 직접 비교해 보세요

나라, 행성, 높이와 여러 단위를 고르고 비율을 확인할 수 있습니다.
