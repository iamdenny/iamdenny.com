Google Analytics와 선택 동의

iamdenny.com 홈페이지와 아홉 개 사용 가이드에서는 방문 통계를 위해 Google Analytics 4(GA4)를 사용할 수 있습니다. 분석은 선택 사항입니다. 이 사이트는 방문자가 분석을 허용하기 전에는 GA4 스크립트를 불러오지 않습니다. 허용 또는 거부 선택은 즉시 반영되고 이 브라우저의 저장소에 기록되어 다음 방문에도 적용됩니다. 아래쪽의 분석 설정에서 언제든 분석을 끄거나 다시 허용할 수 있습니다.

허용하면 Google Analytics가 페이지 이용, 요청, 브라우저·기기 정보와 쿠키 식별자를 처리할 수 있습니다. 페이지 주소에서 쿼리와 조각 식별자는 제거합니다. 홈페이지에서 보내는 사용자 지정 이벤트는 서비스 종류 선택, 가이드 열기, 내비게이션과 링크 이용처럼 제한된 상호작용만 포함합니다. 강의 제목, 참가자 명단, 검색어와 자유 입력 내용은 사용자 지정 분석 이벤트에 포함하지 않습니다.

분석을 끄면 이 사이트는 이후 GA4 이벤트 전송을 중단하고 이 도메인에서 삭제할 수 있는 _ga 쿠키를 지웁니다. 이미 Google에 전송된 데이터는 이 설정으로 되돌릴 수 없습니다. Google의 처리 방식은 Google Analytics 데이터 수집 안내와 Google의 데이터 보호 안내에서 확인할 수 있습니다.

Cloudflare Web Analytics

홈페이지에는 페이지 보기와 성능 통계를 위한 Cloudflare Web Analytics beacon이 있습니다. 이 beacon은 GA4 선택과 별도로 홈페이지에서 불러오며, 사용 가이드와 개인정보 안내 페이지에서는 불러오지 않습니다. Cloudflare는 Web Analytics가 브라우저 Performance API를 사용하고 방문자를 식별하는 쿠키를 쓰지 않는다고 설명합니다. 자세한 내용은 Cloudflare Web Analytics 안내를 확인하세요.

입력 정보와 브라우저 저장

이 사이트의 홈페이지와 개인정보 안내에는 계정, 댓글, 결제, 파일 업로드 또는 서버로 보내는 문의 양식이 없습니다. 홈페이지의 작업 선택, 가이드의 토너먼트 경기 수와 학습 시간 비교 계산은 브라우저에서 동작합니다. 이 계산에 입력한 숫자는 저장하거나 서버로 전송하지 않습니다. 분석 설정은 iamdenny.analytics-consent.v1이라는 키에 허용 또는 거부 값으로 이 브라우저에 저장됩니다. 브라우저가 사이트 저장을 차단하면 분석은 허용되지 않으며, 다음 방문 때 선택을 다시 요청할 수 있습니다.

오류 제보 링크는 이메일 앱을 여는 mailto: 링크입니다. 직접 이메일을 보내면 메시지와 회신 주소가 이메일 제공업체를 거쳐 운영자에게 전달됩니다. 민감한 정보는 포함하지 마세요.

광고와 외부 서비스

iamdenny.com 홈페이지와 사용 가이드는 현재 Google AdSense 광고 스크립트나 광고 슬롯을 사용하지 않습니다. 다른 하위 도메인의 서비스는 별도로 운영되며 각 서비스의 개인정보 안내와 광고 공급업체 설명이 적용됩니다. 하위 서비스를 이용하기 전에 해당 페이지의 안내를 확인해 주세요.

향후 이 사이트에 광고를 도입하면 실제 광고 공급업체, 사용 기술, 정보 처리와 선택 방법을 확인해 이 안내를 갱신합니다. Google 광고와 쿠키에 관한 설명은 Google AdSense 개인정보 안내, Google 게시자 정책, Google 광고 설정에서 확인할 수 있습니다.
